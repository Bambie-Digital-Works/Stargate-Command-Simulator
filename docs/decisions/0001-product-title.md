# Product title decision

Date: 2026-08-27  
Decision owner: `bambiejomurphy-ux`  
Status: approved release-candidate title; legal clearance is not asserted

## Decision

Use **Wormhole Worlds** as the original release-candidate title for the
0.8.0 beta. The title describes the game's original wormhole operations setting
without using franchise names, characters, symbols, dialogue, production designs,
or other franchise material.

The rejected working title `Facility Command` is retained only in historical
repository metadata and migration compatibility. It is not a product-facing
name. `Stargate Command Simulator` is the historical repository name, not the product
title, and is not used in the game UI or release metadata.

## Controlled rename plan

- Keep the product title, installer names, executable metadata, release title,
  README, and project overview aligned to `Wormhole Worlds`.
- Rename the repository slug to `Wormhole-Worlds` and update all GitHub URLs after
  the external repository rename.
- Before a stable commercial launch, repeat the preliminary searches below and
  obtain professional trademark and domain advice.
- Do not market the beta as legally cleared or imply affiliation with any
  third-party franchise.

## Screening evidence

The following preliminary exact-phrase searches were performed on 2026-08-27.
They are discovery evidence only, not a legal clearance opinion:

- [USPTO trademark search](https://www.uspto.gov/trademarks/search): no exact
  `Wormhole Worlds` result was found in the public search review.
- [UKIPO trademark search](https://trademarks.ipo.gov.uk/ipo-tmtext): no exact
  result was found in the public search review.
- [Steam search](https://store.steampowered.com/search/?term=Wormhole%20Worlds):
  no exact product result was found; unrelated products using `Wormhole` exist.
- [itch.io search](https://itch.io/search?q=Wormhole+Worlds): no exact
  product result was found; unrelated wormhole simulations exist.
- [GitHub search](https://github.com/search?q=%22Wormhole+Worlds%22&type=code):
  no matching project using the exact phrase was found in the review.
- [Domain WHOIS lookup](https://www.whois.com/whois/wormholeworlds.com):
  retain the result with the release checklist and recheck before registration;
  search-engine absence is not proof of domain availability.

The terms `wormhole` and `worlds` are ordinary descriptive words with existing
uses. The compound title is therefore treated as a release-candidate decision
that requires a professional review before commercial launch.
