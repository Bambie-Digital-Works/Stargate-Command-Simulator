# Wormhole Worlds 0.8.0-beta.1

This is the first public Windows beta of the original command-centre simulation formerly developed under a temporary franchise-adjacent working title.

## Included

- One complete, deterministic command shift with five escalating incidents.
- Operations, Transit, Survey, Return, Expedition, and Systems consoles.
- Campaign consequences with atomic save, backup, and schema migration support.
- Keyboard, mouse, and controller navigation with remapping.
- UI scaling, high contrast, reduced flashing, captions, independent volume controls, pause, and time-pressure settings.
- Preview update checks with explicit consent and SHA-256 verified installer downloads.
- Per-user Windows installer supporting install, update, repair, downgrade protection, and clean uninstall.

## Important beta notes

- This build is unsigned. Windows SmartScreen may show an unrecognized-app warning. Confirm the installer SHA-256 against `SHA256SUMS.txt` on the GitHub release before running it.
- Player saves and settings are stored separately from the installation and survive updates and normal uninstall.
- The game sends no telemetry. Update checks query only the public GitHub Releases API and fail safely when offline.
- Please report reproducible problems through the repository issue template and include the diagnostics build identity, without personal or copyrighted material.
