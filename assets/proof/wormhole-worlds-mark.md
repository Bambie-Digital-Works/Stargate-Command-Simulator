# Wormhole Worlds mark provenance

The mark was created specifically for this repository on 2026-08-27 as original SVG geometry. It uses only rectangles, circles, and open asymmetric arcs with project-owned colour values. It was not traced from, prompted with, or derived from franchise imagery or third-party artwork.

The project owner requested and approved a full original rebrand and abstract aperture identity as part of the v0.8.0-beta.1 implementation plan. The retained SVG source is the editable master.
